# JavaScript - Web jQuery

Scripts that manipulate the DOM with plain JavaScript (`0-script.js`) and with jQuery (`1` to `9`).

| File | Description |
| --- | --- |
| `0-script.js` | Header text to red using `document.querySelector` |
| `1-script.js` | Header text to red using jQuery |
| `2-script.js` | Header to red on click of `DIV#red_header` |
| `3-script.js` | Adds class `red` to header on click |
| `4-script.js` | Toggles header class between `red` and `green` |
| `5-script.js` | Adds `<li>Item</li>` to `UL.my_list` on click |
| `6-script.js` | Changes header text to `New Header!!!` on click |
| `7-script.js` | Fetches a Star Wars character name into `DIV#character` |
| `8-script.js` | Lists all Star Wars film titles in `UL#list_movies` |
| `9-script.js` | Fetches and displays the French "hello" in `DIV#hello` |
