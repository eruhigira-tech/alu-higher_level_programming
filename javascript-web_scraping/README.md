# JavaScript - Web scraping

Scripts that read and write files with `fs`, and make HTTP requests with the
`request` module (Node.js, semistandard style).

| File | Description |
| --- | --- |
| `0-readme.js` | Reads and prints a file (utf-8) |
| `1-writeme.js` | Writes a string to a file (utf-8) |
| `2-statuscode.js` | Prints the status code of a GET request |
| `3-starwars_title.js` | Prints the title of a Star Wars movie by ID |
| `4-starwars_count.js` | Counts movies featuring Wedge Antilles (character 18) |
| `5-request_store.js` | Stores a web page body in a file |
| `6-completed_tasks.js` | Counts completed tasks per user id |

## Requirements
- Node.js, `request` module (`npm install request --global`, `export NODE_PATH=/usr/lib/node_modules`)
- All files are executable and start with `#!/usr/bin/node`
